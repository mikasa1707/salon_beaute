# 💇 Salon SaaS ERP

Application ERP de gestion complète pour salon de beauté.

Le projet permet de gérer :

- 👥 Clients
- 📅 Rendez-vous / Planning
- 💼 Prestations
- 👨‍💼 Personnel
- 🧾 Facturation
- 💰 Caisse / POS
- 📦 Produits
- 📊 Stock par unité
- 🔄 Mouvements de stock
- 📉 Consommation interne
- 📈 Dashboard statistiques
- 🖨️ Impression PDF / Excel


---

# 🚀 Stack technique

## Frontend

- Angular 21+
- Standalone Components
- TypeScript
- Bootstrap 5
- Font Awesome
- RxJS
- Chart.js


## Backend

- NestJS
- TypeScript
- TypeORM
- MariaDB / MySQL
- JWT Authentication
- REST API
